# Кетсаль · учёт клиентов

Приложение для учёта клиентов мастера перманентного макияжа и камуфляжа студии «Кетсаль»: карты клиентов, процедуры с пигментами и иглами, фото, напоминания о коррекции, отчёты. Работает на iPhone как приложение с экрана «Домой», данные шифруются на устройстве и хранятся на Яндекс Диске салона.

- Техническое задание и план — [SPEC.md](SPEC.md)
- Правила разработки — [CLAUDE.md](CLAUDE.md)
- Утверждённый прототип — [prototype/](prototype/) (выдуманные данные)
- Проверки этапа 0 — [spikes/](spikes/)
